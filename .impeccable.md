## Design Context

### Users
Web developers (PHP, Node, Laravel, WordPress) using DAMP as their local development environment. They spend most of their day in a terminal, IDE, and browser. They value speed and efficiency over visual flourish. They're technical enough to use Docker but want a GUI to manage services, databases, and projects without memorizing CLI flags.

### Brand Personality
Precise, efficient, technical. Every pixel earns its place. No decoration for decoration's sake. The interface should feel like a well-made CLI tool that happens to have a GUI — fast, dense, information-rich, zero fluff.

### Aesthetic Direction
Dark mode only. Developer tool used in dark offices alongside terminals and IDEs.

References: OrbStack (Docker management UI, clean dark), TablePlus (database UI, dark and polished), Warp terminal (modern terminal with thoughtful dark UI), VS Code's sidebar/panels.

Anti-references: Generic admin dashboards (AdminLTE, Material Dashboard), bloated enterprise tools, anything with gradients or glass effects.

Typography: 100% monospace. JetBrains Mono or similar. Every piece of text in the same monospace family — titles, labels, data, buttons. This reinforces the terminal/developer identity.

Color: Existing palette — deep black (#0a0a0a), dark surfaces (#141414, #1a1a1a), green accent (#22c55e) for positive states, red (#ef4444) for errors/stopped, blue (#3b82f6) for links. Green is the primary brand color.

### Design Principles
1. **Density over whitespace** — Show more information, less scrolling. Developers scan, they don't read.
2. **Terminal-native feel** — Monospace everything, monochrome with green accents, status dots, no rounded bubbly UI. Should feel like htop or a TUI with a mouse.
3. **Zero animation unless functional** — No decorative transitions. Loading states and status changes only.
4. **Immediate feedback** — Every action should update the UI instantly (optimistic) or show a clear loading state.
5. **Keyboard-friendly** — Tab navigation, clear focus states, no mouse-only interactions.
