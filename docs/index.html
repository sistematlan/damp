Overview
GitHub README

Dockerized Auto-SSL Modern Platform

A modern, open-source replacement for MAMP, XAMPP, WAMP, and LAMP. One command gets you HTTPS for *.local, shared databases, Mailpit, Redis, and project templates — the same stack the web dashboard and desktop app manage when DAMP is running.

What you get
☍
Caddy
Reverse proxy & automatic HTTPS for local domains
◫
MySQL & PostgreSQL
Shared database servers for all projects
◈
Redis
Cache and sessions
📬
Mailpit
Catch-all SMTP for dev email testing
⚙
Templates
WordPress, PHP, Node, FrankenPHP, and more
◉
Dashboard & app
Web UI at damp.local · Tauri tray app in-repo
