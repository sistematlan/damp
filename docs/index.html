Preguntas Frecuentes

¿DAMP ensucia mi sistema operativo?

En absoluto. Todo DAMP corre dentro de contenedores Docker. Tu Mac, Linux o Windows se mantiene completamente limpio de bases de datos o versiones de PHP conflictivas.

¿Funciona en Windows?

Sí. Aunque tenemos una App gráfica exclusiva para macOS, el CLI de DAMP funciona perfectamente en Linux y en Windows a través de WSL2.

¿Puedo usar diferentes versiones de PHP a la vez?

Totalmente. Puedes tener un proyecto corriendo en PHP 5.6 (legacy) y otro en PHP 8.4 (frankenphp) al mismo tiempo en el mismo navegador. DAMP enruta el tráfico al contenedor correcto.

¿Es gratis para uso comercial?

Sí, DAMP es 100% open source y gratuito. Puedes usarlo para proyectos personales, freelance o dentro de tu empresa sin restricciones.
